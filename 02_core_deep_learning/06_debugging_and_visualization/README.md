# 🔥 06 — Debugging and Visualization

Neural nets fail silently; this notebook teaches how to measure what is going on inside training.
Every notebook here covers one concept with explanation, runnable code, common bugs, and exercises.
All data is synthetic and generated in the notebook, so it runs on CPU with no downloads.
